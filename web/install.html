An online launcher for the original Chat Mockup Maker. Your website stays on its original server, without a redesign.

Install on Android

  1. Open this hosted launcher in Chrome.
  2. Tap ⋮ → Add to Home screen → Install (wording varies).
  3. Open Superyau from your home screen.

Internet is required. This is an unofficial wrapper, not a modified copy of the website. If the embedded website is blank, blocks a feature, or refuses to connect, use “Open original website.” The separate Android APK loads the site directly and does not depend on iframe support.
